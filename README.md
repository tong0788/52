# p5.js 攝影機影像顯示範例

## 功能描述
此程式使用 p5.js 建立一個全螢幕畫布，並將攝影機影像顯示於畫布中央。背景顏色設定為深藍色（`#003049`），影像大小為視窗的 80%。

### 主要功能
1. **背景顏色設定**：使用 `background('#003049')` 設定背景顏色。
2. **攝影機影像**：
   - 使用 `createCapture(VIDEO)` 啟用攝影機。
   - 設定影像大小為視窗的 80%。
   - 使用 `image()` 將影像繪製在畫布中央。
3. **視窗大小調整**：當視窗大小改變時，透過 `windowResized()` 更新畫布和影像大小。

## 執行方式
1. 確保已安裝 [p5.js](https://p5js.org/) 環境。
2. 將 `sketch.js` 放置於專案目錄中。
3. 開啟 p5.js 網頁編輯器或本地伺服器，執行 `sketch.js`。

## 注意事項
- 確保您的瀏覽器允許攝影機存取權限。
- 若影像未顯示，請檢查攝影機是否正常運作。

## 預覽
執行後，畫布將顯示攝影機影像，並自動調整大小以適應視窗。
